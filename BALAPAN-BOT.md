# Балапан-бот: шпаргалка по Promise

Код: `src/balapan-bot.ts`. Запуск: `npm run bot` (нужен `.env` с `BOT_TOKEN`), демо без Telegram: `npm run bot:demo`.

Бот — карманная версия приложения **Балапан**: берёт занятия, этапы развития (CDC) и правила
погоды прямо из данных приложения (`little-moments-growth-guide/src/data/*.json`) через `fetch`.

## Promise в одной фразе

Promise — «чек на будущее значение». Три состояния:

| Состояние | Что значит |
|---|---|
| `pending` | ждём ответа |
| `fulfilled` | успех, есть значение (`resolve`) |
| `rejected` | ошибка (`reject` или `throw`) |

Из `pending` переходит **один раз** и навсегда.

## Матрёшка на примере «📋 План на сегодня»

```
sendTodayPlan            async-функция → сама Promise
└─ Promise.allSettled    ждёт ОБА, никогда не падает
   ├─ getLibrary()       Promise.resolve(кэш)  ИЛИ  Promise.all из 3 файлов
   │  └─ fetchData()     Promise.any из 2 зеркал
   │     └─ getJson()    async: fetch → response.json() — тоже Promise
   └─ getWeatherFast()   Promise.race: погода против таймера 3 с
      ├─ getDayWeather() async: fetch к Open-Meteo
      └─ timeout(3000)   new Promise + setTimeout → reject
```

Каждый слой — Promise, который ждёт Promise слоем ниже. `await` или `.then` «распаковывает» верхний слой.

## Правила матрёшки

1. **`async`-функция всегда возвращает Promise**, даже если внутри `return 5`.
2. **`await`** ждёт Promise и достаёт значение; если Promise упал — бросает ошибку в `try/catch`.
3. **`.then()` возвращает НОВЫЙ Promise.** Вернул Promise из `.then` — цепочка дождётся его (они «склеиваются», а не вкладываются).
4. **`throw` внутри `.then` или `async` = `reject`.** Пример: `pickRandom()` бросает «занятий нет» → срабатывает `.catch`.
5. **Комбинаторы** (`all`, `allSettled`, `race`, `any`) принимают массив Promise и возвращают ОДИН Promise.

## Все варианты Promise в боте

| № | Вариант | Где | Зачем именно здесь |
|---|---|---|---|
| 1 | `new Promise` | `sleep()`, `timeout()`; кнопка «▶️ Таймер» | `setTimeout` не умеет Promise — оборачиваем сами. Таймер «засыпает» на время занятия и напоминает |
| 2 | `.then/.catch/.finally` | `sendRandomActivity()` — «🎯 Занятие» | Цепочка: возраст → библиотека → случайное занятие → отправка. Одна `.catch` ловит ошибку с любого шага |
| 3 | `async/await` + `try/catch` | `sendWalkAdvice()`, `sendQuickIdea()`, `startQuiz()` | То же, что `.then`, но читается сверху вниз |
| 4 | `Promise.all` | `getLibrary()` | 3 файла занятий качаются **одновременно**; без любого библиотека неполная → один упал = упали все |
| 5 | `Promise.allSettled` | `sendTodayPlan()` — «📋 План» | Занятия обязательны, погода — нет. `allSettled` ждёт обоих и не падает: погода упала → план без погоды |
| 6 | `Promise.race` | `getWeatherFast()` | Погода против таймера 3 с: кто первый финишировал, тот и результат. Медленная погода не тормозит план |
| 7 | `Promise.any` | `fetchData()` | Каждый файл — с двух зеркал (GitHub и jsDelivr). Первое **успешное** побеждает; упадут оба → `AggregateError` |
| 8 | `Promise.resolve/reject` | `getLibrary()` (кэш), `requireAge()` | Кэш: сразу готовый Promise, без интернета. Нет возраста — сразу `reject`, цепочка уходит в `.catch` |

## Частые вопросы

**race или any?** `race` — первый **финишировавший**, даже если упал. `any` — первый **успешный**, падения пропускает.
В боте: погоде нужен дедлайн → `race`; данные есть на двух зеркалах → `any`.

**all или allSettled?** `all` — «нужны все», одна ошибка = провал. `allSettled` — «расскажи про каждого», не падает.
В боте: три файла библиотеки нужны все → `all`; погода для плана по желанию → `allSettled`.

**Почему в главном цикле `handleUpdate(update).catch(...)` без `await`?**
С `await` бот ждал бы каждое сообщение: таймер на 10 минут заблокировал бы всех. Без `await` все обрабатываются
параллельно. `.catch` обязателен — необработанный `reject` роняет Node.

**Почему второй запрос быстрее?** Библиотека в кэше → `Promise.resolve(libraryCache)`, интернет не нужен (в демо: 0 мс).

## Что бот умеет кроме команд

- Возраст: просто написать `26` или дату рождения `15.09.2024` — бот сам посчитает месяцы (как `ageInMonths` в приложении).
- Меню-кнопки и кнопки под сообщениями: «✅ Сделали», «▶️ Таймер», «🔄 Другое», «Да / Пока нет».
- «⏱ Есть 5 минут?» — выбор места (дом, кухня, машина, ванная) → быстрое занятие оттуда.
- «🌤 Можно гулять?» и «📍 Погода у меня» (геолокация) — правила приложения: ниже −15 °C, выше +32 °C, ливень или метель → игра дома.
- «🧩 Этапы развития» — квиз по CDC; что стоит обсудить с педиатром, показывается по тем же полям, что в приложении.
- «📊 Прогресс» — занятия по категориям и «минуты вместе» (метрика-северная звезда Балапана).
- «🇰🇿 Қазақша / Русский» — занятия на казахском или русском.

## Ограничения (честно)

- Состояние (возраст, прогресс) хранится в памяти: перезапуск бота — всё сначала. В приложении это лежит в Supabase.
- Погода для плана — по Астане; для своей точки — кнопка «📍 Погода у меня».

## Проверь себя

1. Что вернёт `async function f() { return 5 }`? → `Promise<number>`.
2. Упало зеркало GitHub, jsDelivr ответил — что сделает `Promise.any`? → вернёт ответ jsDelivr.
3. Погода не успела за 3 с — что будет с планом? → `race` упадёт по таймеру, `allSettled` отметит `rejected`, план выйдет без погоды.
4. Упал один из трёх файлов библиотеки — что сделает `Promise.all`? → упадёт целиком.
5. Нет возраста — где окажемся в цепочке «🎯 Занятие»? → `requireAge` → `Promise.reject` → сразу `.catch`.
